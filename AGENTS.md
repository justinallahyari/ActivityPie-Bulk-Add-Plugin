# AI Agent Instructions — ActivityPie Bulk Add Listings Plugin

This file provides authoritative instructions for AI coding agents working on the **Listeo Bulk Add Listings** WordPress plugin (`ActivityPie-Bulk-Add-Plugin`).

---

## 1. Repository Layout

- `plugin/listeo-bulk-add-listings/listeo-bulk-add-listings.php` — Single-file WordPress plugin (class `Listeo_Bulk_Add_Listings`).
- `plugin/listeo-bulk-add-listings/example-template.csv` — Static example CSV matching the dynamic template generated by the plugin.
- `dist/listeo-bulk-add-listings.zip` — Built WordPress-uploadable plugin archive (top-level folder inside zip MUST be `listeo-bulk-add-listings/`).
- `scripts/build-zip.sh` — Rebuilds `dist/listeo-bulk-add-listings.zip` from `plugin/listeo-bulk-add-listings/`.
- `ai-context/environment-profile.json` — Target WordPress + Listeo Core environment details (versions, listing types, taxonomies, custom fields).
- `ai-context/field-mappings.json` — Canonical CSV column → WordPress/Listeo target field mapping & validation rules.
- `ai-context/listeo-core-reference.md` — Technical reference for Listeo Core post types, taxonomies, meta keys, and hooks.
- `docs/` — End-user and admin documentation (`INSTALLATION.md`, `USER_GUIDE.md`, `AI_AGENT_MAINTENANCE.md`).

**Always read `ai-context/environment-profile.json`, `ai-context/field-mappings.json`, and `ai-context/listeo-core-reference.md` before modifying plugin behavior.**

## 2. Core Design Invariants (Do Not Break)

1. **Admin Menu Location:** Submenu page MUST remain under `edit.php?post_type=listing` with title **Bulk Add Listings** and slug `listeo-bulk-add-listings`, gated by `current_user_can( 'manage_options' )`.
2. **Pending Status:** All bulk-imported listings MUST be inserted with `'post_status' => 'pending'` and `'post_type' => 'listing'` unless the user explicitly asks to change this.
3. **All-or-Nothing Validation:** `parse_and_validate_csv()` MUST validate the entire CSV file and collect ALL row/column errors before `create_pending_listing()` is called. If `$parsed['errors']` is non-empty, insert **zero** posts and display all errors.
4. **WordPress Security Standards:**
   - Guard direct file access with `if ( ! defined( 'ABSPATH' ) ) { exit; }`.
   - Verify nonces (`check_admin_referer`) and capabilities (`current_user_can( 'manage_options' )`) on every admin GET action and POST handler.
   - Sanitize all inputs (`sanitize_text_field`, `sanitize_textarea_field`, `sanitize_email`, `esc_url_raw`, `wp_kses_post`, `absint`, `sanitize_key`).
   - Escape all HTML output (`esc_html`, `esc_attr`, `esc_url`).
5. **Listeo Core Compatibility:**
   - Save Listing Title to `post_title`, `post_name`, AND post meta `listing_title` (Listeo keyword search queries `listing_title` meta).
   - Save Description to `post_content` AND post meta `listing_description` (Listeo keyword search queries `listing_description` meta).
   - Save Address to BOTH `_address` and `_friendly_address` (handles `listeo_disable_address` option).
   - Save Listing Type to BOTH `_listing_type` (Listeo Core standard) and `listing_type`.
   - Initialize default Listeo meta via `add_post_meta(..., true)`: `_featured` (`'0'`), `listeo-avg-rating` (`'0'`), `_listing_views_count` (`'0'`).
6. **Public Repository Hygiene:** Never commit server filesystem paths, credentials, user emails/PII, database dumps, or `.DS_Store` files.

## 3. Checklist for Adding or Modifying a CSV Column

Whenever adding, renaming, or removing a CSV column:

1. **Define column metadata** in `Listeo_Bulk_Add_Listings::get_csv_columns()`.
2. **Update header normalization/aliases** in `parse_and_validate_csv()` if alternate column spellings should be accepted.
3. **Add row validation** in `parse_and_validate_csv()` and include the normalized value in `$validated_rows[]`.
4. **Persist the field** in `create_pending_listing()` using the proper WordPress sanitization function or `wp_set_object_terms()` for taxonomies.
5. **Update example CSV outputs:**
   - Dynamic download sample row in `handle_download_template()`
   - Static `plugin/listeo-bulk-add-listings/example-template.csv`
6. **Keep metadata & docs in sync:**
   - Bump `Version:` in the plugin file header (`plugin/listeo-bulk-add-listings/listeo-bulk-add-listings.php`)
   - Update `ai-context/field-mappings.json`
   - Update `docs/USER_GUIDE.md`
7. **Rebuild the distributable zip:**
   ```bash
   ./scripts/build-zip.sh
   ```
8. **Verify before finishing:**
   - If `php` is installed, run `php -l plugin/listeo-bulk-add-listings/listeo-bulk-add-listings.php`.
   - Verify zip contents with `unzip -l dist/listeo-bulk-add-listings.zip` and confirm the top-level directory inside the archive is `listeo-bulk-add-listings/`.
   - Confirm `example-template.csv` header count matches sample row column count.

## 4. Known Environment Context

- Target site runs **WordPress 6.9+**, **PHP 8.3**, **Listeo Theme 2.0.x**, **Listeo Core 2.0.x**, and **Listeo Forms & Fields Editor 2.0.x**.
- Active listing types are retrieved dynamically via `listeo_core_custom_listing_types()->get_listing_types(true)` (currently `service` / Time-Slot Booking and `multi-day-rental` / Multi-Day Rental).
- Custom Policy field meta key is `_service_cancellation_refund_policy`.
- See `ai-context/environment-profile.json` for full details on additional custom fields configured in Listeo Editor (`contact_tab`, `custom_tab`, `service_tab`).
